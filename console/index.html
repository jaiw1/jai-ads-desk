For Meta app review and demos only. The real product is the adsdesk command-line tool and MCP server, which run on your own computer. This page shows the same reads and one safe write, using the same Meta app (“Jai Ads Manager”) and the same login.

Nothing is stored. Your login token lives only in this tab’s memory and is gone when you close or reload it. No cookies, no browser storage, no analytics. Your browser talks directly to Meta. Privacy policy.
